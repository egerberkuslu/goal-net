## Kural

1. **CC0** → doğrudan kullanılır, atıf gerekmez (yine de CREDITS'e yazılır).
2. **CC-BY / CC-BY-SA** → kullanılabilir, ama **atıf zorunlu**: yazar adı ve
   model bağlantısı `CREDITS.md`'ye ve oyun içi künyeye girer. BY-SA ayrıca
   türev eserin aynı lisansla dağıtılmasını ister.
3. **NC (NonCommercial) / ND (NoDerivs)** → **kullanılmaz.** Oyun yayında ve
   parça parça alıp değiştireceğiz; ikisi de bunu yasaklıyor.
4. **Gerçek kulüp forması, arma, oyuncu benzerliği** → lisans ne olursa olsun
   **kullanılmaz.** Sketchfab'daki "football kit" modellerinin çoğu FIFA/PES'ten
   sökülmüş; yükleyenin CC etiketi koymuş olması onu meşru yapmıyor.

## İndirme nasıl olacak

Sketchfab indirmesi OAuth istiyor, yani hesapsız yapılamaz. Kullanıcı hesabı
açtıktan sonra:

1. https://sketchfab.com/settings/password → **API token** kopyalanır
2. `SKETCHFAB_TOKEN=...` olarak `.env`'e yazılır (repoya girmez)
3. `node tools/fetch-models.mjs` — token ile `/v3/models/<uid>/download`
   çağrılır, gelen glTF `vendor-assets/` altına iner, lisans satırı
   `CREDITS.md`'ye eklenir
4. Blender headless script'i modeli oyunun sözleşmesine sokar: ölçek,
   eksen, üçgen bütçesi, birim kutu.

Adım 3'ün script'i token gelene kadar yazılmadı; yazması yarım saat.
